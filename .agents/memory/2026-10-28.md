# 2026-10-28 立项

- 第一版只做 docx、pdf、html。xlsx 和 pptx 放第二版，因为 ppt-rs 还在 0.2，xlsx 的表格结构也跟文档流不太一样。
- 结构沿用 json-render 的扁平 elements + root，方便 AI 流式输出。
- 自定义组件用 YAML/JSON 定义，拼内置组件，不做 Rust 插件。
- PDF 用 Typst 当库，不依赖 LibreOffice。
- 许可证 MIT；推送用这个仓库专属的 ed25519 deploy key。

## docx 渲染器
- 用 docx-rs 0.4.22。图片先用 image 0.25 解码，解不了（SVG 等）就退回 alt 文字，避免 Pic::new panic。
- 每个列表单独一套 numbering，有序列表各自从 1 开始。
- 表格用 fixed 布局，按版心宽度和 widths 比例算列宽。macOS 快速查看会忽略列宽，看效果用 LibreOffice。
- Hark 沙箱内存紧，编译 image 等 crate 时会被杀；改在 LightVela 服务器上 cargo build/test/clippy。

## PDF 渲染器
- typst 0.15.1 当库用：自己实现 World，主文件是生成的 Typst 源码，图片放虚拟路径 `/assets/N.ext`。
- 文字一律写成 Typst 字符串字面量 `#"..."`，不用处理标记语法转义。
- 字体：typst-kit 的 embedded + system，进程内只扫一次（OnceLock）。默认字体列表找不到的不报警告。
- 图片 figure 关掉编号，避免出现「图 1」。

## 自定义组件
- YAML 用 serde-saphyr 2.0（serde_yaml 停更）。
- 定义来源：文档旁 `catalog/` 自动读、`--catalog`、文档里的 `components`（给 MCP 用）。
- 展开：实例 id 给模板根，其余 `实例id.模板id`；`{{prop}}` 整串替换保留类型，夹在文字里按文字替换；`$children` 放实例子元素；最多 32 层防环。
- 顺手修了 PDF 的 bug：带样式的 block 没写 width 会缩到内容宽，右对齐失效。

## 只用 JSON；样式模型按 docs/STYLE.md 实现
- Rei 定：不再支持 YAML，统一 JSON；样式字段平铺、CSS 命名、不做主题色。
- 新增 src/cascade.rs（样式集 extends、组件样式、部位、模板样式、run 样式），src/render/common.rs（列表编号、表格部位、相邻边框）。
- 层叠顺序：继承 < 内置组件默认 < 样式集组件 < 顶层 styles 组件 < 模板 style < 指名自定义组件的键 < 元素 style。模板样式排在通用组件样式之后，和最初草案不同，STYLE.md 已改。
- 组件：新增 Code、InlineCode（run 的 type）；List 项可嵌套；Table 有 look（w:tblLook）。
- docx-rs 不支持 w:tblStylePr、w:tblHeader、分栏：部位逐格直接格式，repeatHeader、columns 在 docx 里不生效。
- typst 列表：编号框宽度用 measure([#m#h(gap)])，单测 measure(m) 会把行尾「、」压成半角，导致换行。
- LibreOffice 预览右对齐的 Word 编号位置和 Word 语义不一致，XML 是对的（编号右边在 left-hanging 处）。
